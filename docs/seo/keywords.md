# Search terms yaml.cafe should answer

The 100 searches below are the ones Ambient's pages should rank for and be cited for. They come from two sources, noted per term:

- **GSC**: queries that already show yaml.cafe in Google Search Console (through 2026-10-31: 163 impressions, 4 clicks, "claude code notifications" alone 41 impressions in the last week).
- **AC**: Google autocomplete, collected 2026-11-03 from about 140 seed phrases (`suggestqueries.google.com`), keeping suggestions that an Ambient page can honestly answer.

Each term maps to the page that should answer it. "Covered" means the page's title, description, body or FAQ uses the phrasing; "added" means this change added it; "gap" means nothing on the site answers it yet.

## Gaps worth a page of their own

These came up in autocomplete, Ambient can answer them, and no page targets them yet:

- **claude code text to speech / tts / read aloud / voice output** — Ambient's Read Aloud (⌥⎋, Mac voice, Kokoro offline, OpenAI or ElevenLabs). Now a homepage FAQ and a sound-guide FAQ; deserves a guide.
- **opencode notification (when done, macos, sound)**, **copilot cli notifications**, **antigravity notification**, **kiro notifications**, **cursor notification when done** — Ambient supports Cursor and Antigravity, and Copilot CLI and OpenCode in beta. One "other agents" guide, or one per agent.
- **claude code on phone / claude code remote ssh** — Ambient follows agents on another machine over ssh but has no phone app; a short, honest page would still get the click.
- **claude code status bar macos / claude code hud / claude code widget mac / claude code mac app** — status-line searches; Ambient's menu bar list is the fit.
- **cloudcode cli process mac** (GSC, 5 impressions) — a misspelling Google already matches to the site.

Rerun the autocomplete collection with the script that produced it (seed one phrase per line, then
`python3 -I suggest.py seeds.txt out.json`; it calls `https://suggestqueries.google.com/complete/search?client=firefox&q=…` for each line). Compare against Search Console's Queries report, filtered to the last 28 days, and promote any query with impressions into the table for its page.
