Questions.

Is Ambient free?

Yes. Download it, connect your agents and use every feature.

Does it send my code or prompts anywhere?

No. Each hook reduces an event to a few short fields — agent, state, project name, a trimmed message — and sends them over a Unix socket to the app on your Mac. The app makes no network requests.

Will it slow my agent down?

No. Hooks finish in about 15 ms, run in the background for Claude Code and Codex, and always exit successfully. If Ambient isn't running, events are simply dropped.

What does it change on my Mac?

It adds its own hook entries to ~/.claude/settings.json, ~/.codex/hooks.json and ~/.gemini/settings.json, keeps a backup of each file, and removes only its own entries when you disconnect an agent or run ambient uninstall.

Which Macs does it run on?

macOS 14 or later, on Apple silicon and Intel. It's designed for MacBooks with a notch; on other displays the island sits at the top center of the menu bar.

Why do you ask for my name and email?

Downloading adds you to the waitlist for Ambient news and new features. We use your details only for that. See the privacy notice.
