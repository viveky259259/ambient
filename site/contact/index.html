Help and bug reports

Start with ~/.ambient/bin/ambient doctor in a terminal. It checks the app, each agent's hooks and the connection between them, and often names the fix. If it doesn't, email us and include:

  • the output of ambient doctor,
  • your macOS version and Ambient version (Settings › General),
  • which agent and which terminal or app it runs in,
  • what you expected to see and what you saw instead.

Agents read hook settings when they start, so restart sessions that were open before you connected Ambient. For Codex, approve Ambient's hooks once with /hooks.
