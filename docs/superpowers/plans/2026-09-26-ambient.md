# Ambient Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a notarized macOS app that turns Claude Code / Codex / Gemini CLI hook events into ambient
desktop signals (notch island, notifications + sound, menu bar, Dock glow).

**Architecture:** Agent hooks invoke the bundled `ambient` CLI, which normalizes the payload and sends one
JSON line over a Unix socket to Ambient.app. A pure `AmbientCore` reducer turns events into per-session
state and an aggregate; AppKit/SwiftUI surfaces render it.

**Tech Stack:** Swift 6 toolchain (language mode 5 for the app target), SwiftPM, AppKit, SwiftUI,
UserNotifications, ServiceManagement, ApplicationServices (AX), Swift Testing.

**Spec:** `docs/superpowers/specs/2026-09-26-ambient-design.md`

## Global Constraints

- macOS 14.0 minimum, arm64 + x86_64 universal release build.
- Bundle id `com.viveky259259.Ambient`; app executable `Ambient`; CLI at `Contents/Helpers/ambient`.
- Ambient home `~/.ambient` (override with `AMBIENT_HOME`): `ambient.sock`, `bin/ambient`, `backups/`, `logs/`.
- Hook marker substring: `.ambient/bin/ambient`. Hook command:
  `[ -x "$HOME/.ambient/bin/ambient" ] && "$HOME/.ambient/bin/ambient" hook <agent> || true`.
- The hook CLI always exits 0, never writes stdout, and has a 250 ms socket timeout.
- Wire strings truncated: tool detail ≤ 80 chars, summary/message ≤ 160 chars. Prompts and tool output never sent.
- State colors: working coral `#D97757` (Codex `#10A37F`, Gemini `#4F8DF7`), waiting `#F5A524`,
  done `#3FB950`, error `#F85149`.
- Timeouts: busy→idle after 600 s silence; idle sessions dropped after 7200 s; done-notification threshold 20 s.

### Task 1: Package scaffold + event model

**Files:** Create `Package.swift`, `Sources/AmbientCore/Event.swift`, `Sources/AmbientCore/Text.swift`,
`Tests/AmbientCoreTests/EventTests.swift`, `.gitignore`.

**Produces:**
- `enum AgentKind: String, Codable, CaseIterable { case claude, codex, gemini }` with `displayName`.
- `enum EventKind: Codable, Equatable` — cases `sessionStarted`, `promptSubmitted`,
  `toolStarted(name: String, detail: String?)`, `toolFinished(name: String, failed: Bool)`,
  `needsInput(reason: String, message: String?)`, `compactStarted`, `compactFinished`,
  `subagentStarted`, `subagentFinished`, `turnCompleted(summary: String?)`, `turnFailed(message: String?)`,
  `sessionEnded`, `notice(message: String)`.
- `struct HostInfo: Codable, Equatable { bundleId: String?; termProgram: String?; pids: [Int32] }`.
- `struct AgentEvent: Codable, Equatable { agent; sessionId; cwd: String?; kind; timestamp: Date; host: HostInfo? }`
  with computed `project: String?` (last path component of cwd).
- `Text.truncate(_:max:)` — collapses whitespace, trims, appends "…" when cut, respects grapheme clusters.

Tests: Codable round trip for every `EventKind` case; `truncate` on short/long/multiline/emoji input.

### Task 2: Agent adapters

**Files:** Create `Sources/AmbientCore/Adapters/HookPayload.swift`, `ClaudeAdapter.swift`,
`GeminiAdapter.swift`, `AdapterRegistry.swift`; test `Tests/AmbientCoreTests/AdapterTests.swift`.

**Produces:**
- `struct HookPayload` wrapping `[String: Any]` from stdin with typed accessors (`string(_:)`, `object(_:)`).
- `protocol AgentAdapter { static func normalize(_ p: HookPayload, eventHint: String?) -> EventKind? }`.
- `ClaudeAdapter` (also used for Codex, whose hook names match): mapping table from the spec. Tool detail:
  Bash → `command` head; Edit/Write/Read/NotebookEdit → file basename; Grep/Glob → `pattern`;
  WebFetch → host; Task/Agent → `description`; MCP `mcp__server__tool` → `server · tool`; else nil.
  Notification: `permission_prompt|elicitation_dialog|elicitation_url_dialog|agent_needs_input` → needsInput;
  `idle_prompt` → nil (no state change); others → `notice`.
- `GeminiAdapter`: BeforeAgent/AfterAgent/BeforeTool/AfterTool/Notification/PreCompress/SessionStart/SessionEnd.
- `AdapterRegistry.event(agent:payload:eventHint:now:host:) -> AgentEvent?` — nil when session id missing
  or event unmapped.

Tests: one fixture per mapped event per agent; unknown event → nil; missing session_id → nil; Bash command
truncated to 80; MCP naming.

### Task 3: Session reducer + aggregate

**Files:** Create `Sources/AmbientCore/Session.swift`, `SessionStore.swift`; test `SessionStoreTests.swift`.

**Produces:**
- `enum Activity: Equatable { idle, thinking, tool(name, detail), compacting, waiting(reason, message), done(summary), error(message) }`
  with `priority(acknowledged:) -> Int` and `isBusy`.
- `enum Mood: Int, Comparable { idle=0, working=2, done=3, error=4, waiting=5 }`.
- `struct Session: Identifiable, Equatable { id: String /* agent:sessionId */; agent; sessionId; project; cwd; host;
  activity; activitySince: Date; lastEventAt: Date; turnStartedAt: Date?; toolCount: Int; subagents: Int; acknowledged: Bool }`
  with `mood`, `turnDuration(now:)`.
- `struct Transition { session: Session; previous: Activity? }` returned from apply so surfaces can react.
- `final class SessionStore` (not thread-safe; owned by main actor in app):
  `apply(_ e: AgentEvent) -> Transition?`, `acknowledge(sessionID:)`, `acknowledge(hostBundleId:)`,
  `sweep(now:) -> [Transition]`, `sessions: [Session]` (sorted by priority, then recency), `mood: Mood`,
  `busyCount`, `waitingCount`.

Tests: prompt→tool→toolFinished→done path; out-of-order event ignored; needsInput then toolStarted
returns to tool; waiting outranks done; ack lowers mood; prompt resets ack; sweep turns stale busy into idle
and drops old idle; sessionEnded removes; subagent counter never negative; compact returns to thinking.

### Task 4: Wire format + socket

**Files:** Create `Sources/AmbientCore/Wire.swift`, `Paths.swift`, `UnixSocket.swift`; test `SocketTests.swift`.

**Produces:**
- `enum WireMessage: Codable { case event(AgentEvent), statusRequest, status([SessionSnapshot]), ping, pong }`
  encoded as one JSON line; `SessionSnapshot` = Codable subset of `Session` for `ambient status`.
- `struct AmbientPaths { home, socket, binDir, cliLink, backups, logs; static func current(env:) }`.
- `UnixSocketClient.send(_ data: Data, to path: String, timeout: TimeInterval, expectReply: Bool) throws -> Data?`.
- `final class UnixSocketServer { init(path:); start(handler: @escaping (Data) -> Data?) throws; stop() }` —
  unlinks stale socket, chmod 0600, accepts on a background queue, reads one line (max 64 KB).

Tests: round trip event; request/reply; send to missing socket throws quickly (<300 ms); oversized line rejected.

### Task 5: Order-preserving JSON + hook installers

**Files:** Create `Sources/AmbientCore/JSON/JSONValue.swift`, `JSONParser.swift`, `JSONWriter.swift`,
`Sources/AmbientCore/Install/HookInstaller.swift`, `AgentHookSpec.swift`; tests `JSONTests.swift`, `InstallerTests.swift`.

**Produces:**
- `indirect enum JSONValue { null, bool, number(String), string, array([JSONValue]), object([(String, JSONValue)]) }`
  with subscript helpers; parser preserves key order and number lexemes; writer pretty-prints with 2-space
  indent (Claude/Gemini style) and escapes like JSON.stringify.
- `struct AgentHookSpec { agent; configPath(home:) ; events: [String]; hookEntry(command:) -> JSONValue }`
  for Claude (async, timeout 5), Codex (async, timeout 5, statusMessage omitted), Gemini (name "ambient", timeout 1500).
- `struct HookInstaller { install(agent:, home:, dryRun:) throws -> InstallReport; uninstall(...);
  status(agent:, home:) -> InstallState (.notInstalled, .installed, .partial, .configMissing, .agentMissing) }`.
  Backup to `~/.ambient/backups/<agent>-<yyyyMMdd-HHmmss>.json`, atomic write, re-parse verification.

Tests: parse/write round trip keeps order; install into empty/missing file; install preserves foreign hooks
and unrelated keys; reinstall idempotent (byte-identical); uninstall restores original structure and prunes
empty `hooks`; unparsable file throws without writing.

### Task 6: CLI

**Files:** Create `Sources/ambient/main.swift`, `Commands.swift`, `Host.swift`; test `Tests/AmbientCoreTests/HostTests.swift` (logic that lives in Core).

**Produces:** `ambient hook <agent> [event]`, `install [--agent …|--all] [--dry-run]`, `uninstall`, `status [--json]`,
`doctor`, `emit <mood> [--project] [--agent]`, `demo`, `version`, `help`. Host capture: `__CFBundleIdentifier`,
`TERM_PROGRAM`, parent pid chain via `sysctl(KERN_PROC_PID)` (max 12 levels).

Verification: `echo '{…}' | swift run ambient hook claude` exits 0 with no output when app absent;
`time` under 30 ms release build.

### Task 7: App shell — server, store, menu bar

**Files:** Create `Sources/AmbientApp/main.swift`, `AppDelegate.swift`, `AppModel.swift`, `Settings.swift`,
`MenuBarController.swift`, `HostActivator.swift`, `Palette.swift`; `Resources/Info.plist`, `Resources/Ambient.entitlements`.

`AppModel` (`@MainActor ObservableObject`): owns `SessionStore`, receives events from the socket (hop to main),
publishes `sessions`, `mood`, emits transitions to surfaces; 5 s sweep timer; observes
`NSWorkspace.didActivateApplicationNotification` to acknowledge. Single-instance guard. Refreshes
`~/.ambient/bin/ambient` symlink at launch.

### Task 8: Notch island

**Files:** Create `Sources/AmbientApp/Island/IslandPanel.swift`, `IslandView.swift`, `IslandGeometry.swift`,
`StateGlyph.swift`.

Panel: borderless non-activating `NSPanel`, level `.statusBar + 1`, all spaces + full screen auxiliary,
sized for expanded state, `ignoresMouseEvents` toggled by hot-rect tracking. Geometry from
`NSScreen.safeAreaInsets` / `auxiliaryTopLeftArea` / `auxiliaryTopRightArea`; floating pill fallback.
Bloom on transitions to waiting/done/error for 4 s. Hover expands to session list; click row → activate host.
