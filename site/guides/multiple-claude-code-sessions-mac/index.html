How to run multiple Claude Code sessions at once on a Mac

Updated October 9, 2026 · 5 min read

Give each session its own git worktree with claude --worktree <name>, so their edits don't collide. Then keep track of them in one place: Claude Code's agent view (claude agents) for background sessions, or Ambient's notch island and menu bar for every session, in any terminal, editor or the Claude desktop app, most urgent first.

1. Keep their edits apart with worktrees

Two sessions editing the same checkout will trip over each other. A git worktree is a separate checkout on its own branch:

claude --worktree feature-auth     # terminal 1
claude --worktree fix-cache-bug    # terminal 2

The repository needs at least one commit first.

2. Run some in the background with agent view

Claude Code's agent view (a research preview) is one screen for all your background sessions:

claude agents                      # open agent view
claude --bg "upgrade the test runner"   # start a background session from the shell

Inside a session, /bg moves it to the background. Background sessions keep running with no terminal open, move into their own worktree under .claude/worktrees/ before editing files, and are grouped by state, with the ones that need input at the top in yellow. The terminal tab title shows a count, such as 2 awaiting input, and while agent view is open Claude Code also sends a notification when one needs you, finishes or fails.

3. Or one per terminal tab or tmux pane

Plenty of people simply run each session in its own tab or tmux pane. It works, until you're switching tabs to find the one that's waiting.

4. See every session at once

Ambient keeps a state for every session and shows the most urgent one at the notch: needs you, then error, then done, then working. Hover the island for the full list, or open the menu bar list. A click takes you to the exact place each one runs:

Agent view or Ambient?

They answer different questions, and work together. Agent view manages Claude Code's own background sessions inside a terminal. Ambient watches every session you start, foreground or background, in any app, and tells you at a glance without a terminal open.

Common questions

Will two Claude Code sessions overwrite each other's files?

They can if they work in the same checkout. Start each with claude --worktree <name> so each edits its own branch in its own folder.

Do parallel sessions share context?

No. Each session is its own conversation with its own context.

How do I find the session that's waiting for me?

In agent view, sessions that need input sit at the top in yellow, and the terminal tab title shows how many are waiting. With Ambient, the notch turns amber and ambient open jumps straight to the session that needs you most.
