How to set up Claude Code in tmux

Updated October 31, 2026 · 4 min read

Claude Code runs in tmux with no setup, but tmux blocks its notifications and Shift+Enter until you add four lines to ~/.tmux.conf and run tmux source-file ~/.tmux.conf. After that, give each session its own window and git worktree, and tmux keeps them all running when you close the terminal.

Add these lines to tmux

Put this in ~/.tmux.conf, then run tmux source-file ~/.tmux.conf to apply it to the running server:

set -g allow-passthrough on
set -g focus-events on
set -s extended-keys on
set -as terminal-features 'xterm*:extkeys'
LineWhat it fixes
allow-passthroughNotifications and the progress bar reach your outer terminal instead of stopping at tmux.
focus-eventstmux tells Claude Code when you enter or leave the pane. More on focus events.
extended-keys and extkeystmux can tell Shift+Enter from Enter, so Shift+Enter inserts a newline instead of sending your prompt.

Without the last two lines you can still add a newline with Ctrl+J, or by typing \ and pressing Enter. If you use /terminal-setup, run it in your terminal outside tmux, because it writes to that terminal's own configuration.

Start one window per session

Name a tmux session for your agents and give each Claude Code session a window and a worktree, so their edits don't collide:

tmux new-session -d -s agents -n auth 'claude --worktree feature-auth'
tmux new-window -t agents -n cache 'claude --worktree fix-cache-bug'
tmux attach -t agents

The repository needs at least one commit first. Close the terminal and the sessions keep running. tmux attach -t agents brings them back, and Ctrl+b w lists every window.

Know which pane needs you

tmux shows one screen at a time, so a session waiting in another window is easy to miss. With "preferredNotifChannel": "terminal_bell" in ~/.claude/settings.json, tmux flags the window that rang the bell in its status line. The tmux notifications guide covers that and a hook that messages tmux.

Common questions

Do I need tmux to run Claude Code?

No. Claude Code works in any terminal. tmux helps when you want several sessions in one place, or sessions that survive closing the terminal.

Why does Shift+Enter send my prompt in tmux?

tmux can't tell Shift+Enter from Enter until extended keys are on. Add set -s extended-keys on and set -as terminal-features 'xterm*:extkeys' to ~/.tmux.conf, or press Ctrl+J for a newline.

Does Claude Code keep running after I close the terminal?

Inside tmux, yes. The tmux server keeps the session alive, and tmux attach brings it back.
