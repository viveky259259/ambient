Claude Code notification apps for Mac, compared

Updated October 9, 2026 · 6 min read. Ambient is our app; we've tried to be fair, and every other app's details come from its own site on this date

If you want to approve or deny Claude Code's permission requests from the notch, look at Vibe Island (paid, about 30 agents), Vibe Notch (free and open source) or Claude Pulse (free, with plan limits). For a free app that covers Claude Code, Codex and Gemini CLI, takes you back to the exact tab, tmux pane or desktop-app chat, and runs on Intel Macs and macOS 14, use Ambient. AI Done Now is a paid menu bar notifier without a notch.

What each does best

Ambient

A calm status for every agent session: a notch island, banners with one chime per state, a menu bar list, a glow along the Dock and an optional living wallpaper. A click opens the exact Claude or Codex desktop-app chat, Terminal or iTerm2 tab, or tmux pane. It stays quiet while you're already looking at the agent, makes no network requests, and runs on Intel Macs and macOS 14. It doesn't approve permissions for you, track plan usage or watch remote machines.

Vibe Island

The broadest: about 30 agents, Allow and Deny buttons in the notch, a jump to the exact tab and split pane, sound alerts, plan review, usage tracking and SSH monitoring of remote machines. Paid, with a free trial; its site says everything stays on your Mac.

Vibe Notch

Free and open source (formerly Claude Island): monitors multiple Claude Code CLI sessions from the notch, approves or denies tools there, and shows chat history. Claude Code only, macOS 15.6 or later.

Claude Pulse

Free: approves tool calls from the notch with batch approval that still stops for dangerous commands, tracks multiple sessions, and shows your 5-hour and weekly plan limits. Claude Code only, on notched Apple silicon MacBooks with macOS 15 or later.

AI Done Now

A paid menu bar app: native banners with different sounds for finished tasks and permission requests, and a click that opens Cursor or Terminal. No notch display.

Which should you pick?

  • You want to answer permission prompts without leaving what you're doing: Vibe Island, Vibe Notch or Claude Pulse.
  • You run Claude Code, Codex and Gemini CLI, or use the Claude or Codex desktop apps, and want to land back in the exact tab, pane or chat: Ambient.
  • You're on an Intel Mac or macOS 14: Ambient.
  • You only want a sound and a banner: Claude Code's built-in notifications or a hook may be enough. See Claude Code notifications on Mac.

Common questions

Is there a free Claude Code notch app for Mac?

Yes. Ambient, Vibe Notch and Claude Pulse are free. Vibe Island offers a free trial.

Which apps can approve Claude Code permissions from the notch?

Vibe Island, Vibe Notch and Claude Pulse show Allow and Deny in the notch. Ambient alerts you the moment Claude asks and takes you back to the session, where you answer in Claude Code.

Do these apps send my code anywhere?

Ambient makes no network requests. Vibe Island's site says everything stays on your Mac, Claude Pulse says it runs entirely on your machine, and AI Done Now says your code and prompts never leave your Mac, though it sends license details.
